# Voice readiness

ElevenLabs selection now checks exact configured voice/model access and completes a short PCM 24 kHz synthesis probe. The probe is discarded without playback, uses normal speech accounting and provider/development limits, and may be billable. Metadata alone does not establish format readiness.

Validation has a 25-second overall deadline, a 240,000-byte cap and sample-alignment/minimum-output checks. Successful results are cached for five minutes against a digest of private key/voice/model/format configuration. Concurrent checks serialize. Stream failures invalidate cached readiness; ordinary user interruption does not. The next Conversation start rechecks invalid or expired readiness.

Explicit ElevenLabs still reports invalid setup; Automatic follows the existing OpenAI fallback policy. The Speech voice panel includes Preview active voice. Start Conversation to establish the configured audio sink, then click Preview; Stop and spoken interruption use the ordinary local playback path. Preview uses the active provider, interrupts any current answer, makes no Astra call and adds no preview text to conversation history. It never substitutes another voice on failure. Saved provider changes still apply at the next Conversation start. Idle/standalone setup preview without starting Conversation remains a possible usability improvement, not a claimed capability. Raw PCM has no sample-rate header: successful delivery in the requested API format does not qualify physical sample-clock accuracy or playback.

Official contract checked on 2026-09-11: [ElevenLabs WebSocket TTS](https://elevenlabs.io/docs/api-reference/text-to-speech/v-1-text-to-speech-voice-id-stream-input).

Each speech adapter has an independent circuit breaker. Three consecutive stream failures pause new synthesis for 30 seconds. After that, one speech request may test recovery; concurrent requests stay blocked until it finishes. A successful recovery closes the breaker, a failure restarts the delay, and user cancellation releases the recovery slot without counting as failure. No background billable retry runs. A blocked request creates no provider attempt or usage charge record. Provider plan limits and development-budget restrictions still apply and are not reset by circuit recovery.

The Speech voice panel shows paused/recovery state while open; authenticated voice status also exposes failure counts and remaining backoff. Existing per-utterance fallback rules remain in force, including no replay after partial output. Preview still never substitutes voices. This backoff is process-local; restarting the app starts new circuit state but does not bypass persisted development usage accounting.

If the allowed speech attempts fail, the current model answer continues as text. Iago flushes pending playback, closes acknowledgment of that speech epoch and shows a speech error that remains visible when text completes. It does not retry the rest of that answer aloud. Generated but unheard text stays out of heard-answer history; optional transcript metadata still distinguishes generated text from the heard prefix. Stop, End or a new user turn still cancel the remaining model work. Speech-dependent thumb questions are unavailable after speech failure. This behavior does not qualify physical silence or recognition accuracy.
