Inspected actual `ObjectDetectorOptions` and `GestureRecognizerOptions` signatures. Assets live in ignored `local-data/models`. The declared object labels come from the official label map. To reproduce: `uv run --extra vision python -m reachy_brain.vision.detectors --download`. Hash mismatch fails explicitly rather than silently accepting a different model.

Real CPU inference on blank synthetic images and a separate spawned worker passed. This establishes packaging, method compatibility, model loading and lifecycle—not real-world detection accuracy, wave recall, thumb responses or standalone Reachy performance. Temporal wave and presence tests use synthetic tracks and remain separate from the mandatory real recordings.
# Reachy local SDK verification — 2026-09-11

`uv sync --locked --group dev --extra vision --extra robot` installed Reachy Mini 1.10.0 and its locked GStreamer bundle on native Windows. Reviewed the installed `reachy_mini.py`, `media_manager.py`, `audio_base.py` and `audio_gstreamer.py`, together with the official [Python SDK guide](https://huggingface.co/docs/reachy_mini/en/SDK/python-sdk) and [media API](https://huggingface.co/docs/reachy_mini/API/media).

The robot-local adapter explicitly selects `connection_mode=localhost_only`, `media_backend=local`, and an existing daemon. It queries actual rates/channels and uses the SDK's frame, JPEG snapshot, microphone and PCM-output methods. The installed GStreamer audio implementation's `clear_player()` flushes queued output; `stop_playing()` transitions the shared pipeline to NULL. Therefore interruption uses the local flush while End shuts down capture/playback. Full-duplex microphone continuity through a flush still requires physical measurement.

Motion uses the actual `cancel_move`, current-head-pose and `set_target` methods with application bounds. Tests import the real SDK types and verify the adapter call sequence against an explicitly fake receiver; no robot was connected. Robot-local supervisor tests are deterministic, not evidence of physical silence or motor stopping. Edge transport, deployment profile wiring, acoustic qualification and effective onboard rates remain outstanding.


MCP HTTP credential integration was checked against installed MCP 2.2 and httpx2 2.12.0 source: `Client` accepts a transport context manager; `mcp.client.streamable_http.streamable_http_client` accepts an `http_client`; that SDK uses `httpx2.AsyncClient` and its asynchronous Auth interface. The application now declares httpx2 directly and the lock remains resolved. Actual authenticated local Streamable HTTP discovery/tool round trips are recorded in `local-data/evidence/stage-mcp-credentials-final/offline-subset.json`. This validates the installed versions and synthetic server, not compatibility with every external MCP server or production OAuth provider.


Cost-accounting references checked 2026-09-11: [Astra model pricing](https://developers.openai.com/api/docs/models/gpt-6-astra), [GPT Live Transcribe pricing](https://developers.openai.com/api/docs/models/gpt-live-transcribe), and [Realtime transcription](https://developers.openai.com/api/docs/guides/realtime-transcription). Installed OpenAI ResponseUsage declares input tokens, cached/cache-write details, and output tokens with reasoning detail. The shipped Astra standard-tier table uses per-million rates 10 input, 1 cached, 12.5 cache-write and 50 output USD; above 272,000 input tokens it applies 2x input/cache and 1.5x output. Reasoning detail is not added again to output totals. Unsupported service tiers/models or malformed/incomplete usage remain unpriced. This table is an estimate source, not an invoice or complete account-spend report.

ElevenLabs stream completion reviewed 2026-09-11 against its [realtime TTS guide](https://elevenlabs.io/docs/eleven-api/guides/how-to/websockets/realtime-tts), which exposes `isFinal` as the synthesis terminal signal. Iago conservatively requires boolean `true`; a clean transport close without it is recorded as an incomplete stream, not successful synthesis. This is an application completion policy, not a claim that every server close represents a billing failure. Fallback remains permitted only before any audio has been dispatched; partial speech is never replayed automatically. Synthetic adapter-to-speech-controller checks cover absent, false and malformed terminal flags both before and after audio.

Astra attempt accounting reviewed against the official [Response schema](https://developers.openai.com/api/reference/python/resources/responses/methods/retrieve) and installed OpenAI SDK `ResponseCreatedEvent`, `ResponseIncompleteEvent` and `ResponseUsage` definitions. Response IDs are available before completion; usage is optional and contains input/output details when supplied. Iago retains returned usage on terminal failure/incompletion and uses a local attempt identity when interrupted before a response ID arrives. It does not enable response storage or retrieve canceled private responses to invent missing billing evidence. Synthetic tests use the installed ResponseUsage type with fake transport events; they do not qualify actual provider billing.

Transcription usage checked against the official [Realtime transcription guide](https://developers.openai.com/api/docs/guides/realtime-transcription) and installed `ConversationItemInputAudioTranscriptionCompletedEvent`: usage can contain duration seconds or token counts with optional audio/text input details. The application copies only validated numeric counters and deduplicates item/content identity, with a 10,000-item session capacity. It does not infer zero billing from omitted usage or missing details.

Returned-duration pricing verified against the official [GPT Live Transcribe model page](https://developers.openai.com/api/docs/models/gpt-live-transcribe), accessed 2026-09-11: USD 0.017 per realtime audio minute. The dated table estimates only returned duration, with separate unknown remainder. The live synthetic speech/transcription evidence at `local-data/evidence/stage-transcription-pricing-live/live-provider-subset.json` returned 4.0 seconds for 158,400 uploaded PCM bytes (3.3 seconds at 24 kHz mono PCM16); it records an estimate of USD 0.0011333333333333334. The differing durations are observed, not an inferred universal billing-rounding rule. OpenAI TTS and ElevenLabs estimates remain unknown where this implementation lacks supported returned billing units and corresponding rates.
# Parser process memory contracts

Verified 2026-09-11 against [Microsoft extended job limits](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-jobobject_extended_limit_information) and [SetInformationJobObject](https://learn.microsoft.com/en-us/windows/win32/api/jobapi2/nf-jobapi2-setinformationjobobject): the per-process memory flag limits committed virtual memory. It does not mean total reserved address space or physical RSS. The parser child creates and joins its own unnamed job before importing extraction libraries; its handle lives until child exit.

The Linux path uses [Python resource limits](https://docs.python.org/3/library/resource.html), setting RLIMIT_AS without increasing an inherited lower limit. Linux/Reachy qualification remains pending; Windows results do not qualify its address-space behavior or robot resource rates.
